# Surface: owner guide to the Penpot prototype (guide/index.html)

Scope: one Read-mode page in Russian. Reader: the user himself (personal joke build) and, in `?clean` mode, the 1000 Islands owner. Job: open the prototype (Penpot phone / desktop / emails / admin, HTML prototype), make a free Penpot account, add it to the home screen, leave and answer comments; what to comment on at stage 1 and what is not clickable on purpose.

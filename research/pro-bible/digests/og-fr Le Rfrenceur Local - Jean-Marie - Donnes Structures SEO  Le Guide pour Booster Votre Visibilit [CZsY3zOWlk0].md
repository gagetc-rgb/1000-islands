## Core thesis
Structured data is standardised markup that lets search engines understand a page and trigger rich results; the two big families are schema.org (content) and Open Graph (social previews); use the common types (LocalBusiness, Product, FAQ, Organization, Recipe, BreadcrumbList, Author, Article), implement via JSON-LD or an SEO plugin, then test.

## Claims and advice
- [SEO] Structured data are format-standardised data that give search engines precise, usable information, whatever the page layout. (0:00-1:00) — type: evidence
- [SEO] Benefits: better understanding by Google, rich results, more clicks. (2:02-3:03) — type: opinion
- [SEO] Schema.org and Open Graph are the two big types in 2025; they are compatible and can be used together; Open Graph gives the title, site name and thumbnail when a link is shared. (3:03-4:05) — type: evidence
- [SEO] Most common markups: LocalBusiness (home page of a local business or pages of local outlets); Product (price, rating, stock; "primordial" for e-commerce); FAQ (he believes Google no longer shows FAQ results, but adds it "in case"); Organization (name, logo, founding year); Recipe; BreadcrumbList (suits all sites, plugin-generated); Author (E-E-A-T); Article. (4:05-8:12) — type: opinion (experience)
- [SEO] Implement by generating JSON-LD (with a generator or a chatbot) and pasting it in the HTML, or with an SEO plugin on WordPress (Rank Math, SEOPress); the plugin route is the one he recommends. (8:12-9:12) — type: practice
- [SEO] Validate with Google's Rich Results Test and the schema.org validator. (9:12-10:13) — type: practice

## Techniques and steps
1. Pick types (LocalBusiness, Organization, BreadcrumbList, Article).
2. Add via plugin or JSON-LD.
3. Test with both validators.

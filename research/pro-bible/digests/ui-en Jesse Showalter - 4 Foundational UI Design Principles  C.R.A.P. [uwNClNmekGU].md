## Core thesis
Four principles (contrast, repetition, alignment, proximity) turn a messy layout into an organised one; each is demonstrated by fixing a deliberately bad layout.

## Claims and advice
- [UI] Contrast: establish hierarchy and a focal point with size, weight, colour, typography and imagery; headline from 24 px to about 54 px, medium to semi-bold, a bold accent colour on the key word ("not an exact formula"). (0:00-3:04) — type: practice
- [UI] Repetition: use the same treatments for the same kinds of element so users can learn the interface; "it reduces confusion". Demo: align all cards to one baseline, face all bike images the same way. (3:04-4:04) — type: practice
- [UI] Alignment: line up edges and centres; it "creates rhythm... brings order to chaos"; aligned elements form invisible axes that keep even a rotated or experimental layout feeling ordered. (4:04-7:07) — type: practice
- [UI] Proximity: put related items close together and unrelated ones apart; a headline, its body and a button need grouping so users know what belongs together; a "Black Friday" note goes under the button it relates to. (7:07-8:09) — type: practice (consistent with Chainlift's relationship-strength rule)
- [UI] After applying all four, the layout is "about a hundred times better" (a figure of speech). (8:09) — type: opinion

## Techniques and steps
1. Add contrast: size, weight, colour for headline and focal image.
2. Repeat the same layout and spacing across cards.
3. Align elements to shared edges.
4. Group related items; separate unrelated.

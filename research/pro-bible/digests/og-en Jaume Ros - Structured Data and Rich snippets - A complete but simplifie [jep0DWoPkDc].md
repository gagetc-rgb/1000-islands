## Core thesis
Structured data is a small piece of code that helps Google understand the page and can produce rich results (star ratings, FAQs); use schema.org types in JSON-LD, or a plugin if on WordPress.

## Claims and advice
- [SEO] Rich results (recipe ratings and cook time, review stars, FAQ) need structured data. (0:00-1:01) — type: evidence
- [SEO] Example: the page source of a site shows `aggregateRating` and FAQ markup matching exactly what appears in the result (4.8 rating, 146,000 votes). (1:01-3:04) — type: evidence
- [SEO] Search engines are smarter but still cannot read and understand pages as quickly as humans, so structured data adds support. (3:04) — type: opinion
- [SEO] schema.org started by Google, Bing and Yahoo defines types and properties (Book, Movie, Recipe); each type page lists properties and examples in three syntaxes (microdata, RDFa, JSON-LD). (3:04-6:06) — type: evidence
- [SEO] Google's documentation recommends JSON-LD. (7:07) — type: evidence
- [SEO] For WordPress use a structured-data plugin; some are type-specific (reviews, events, recipes), others general builders; check which schema types they support; he paid for a recipe plugin that provides form fields. (8:07-9:08) — type: practice

## Techniques and steps
1. Pick the schema.org type; see the example for JSON-LD.
2. Use a plugin or add the JSON-LD block.

## Core thesis
To earn from web design today, learn Figma and Tilda (no-code builder), learn the whole project cycle (client call, brief, commercial proposal, prototype, design concept, mobile version, layout and integrations) and soft skills; practise rather than only study.

## Claims and advice
- [UX][AIW] Tools: Figma for structure, prototype and design; Tilda to build the site without code and add integrations such as booking; clients want a finished product, not just a Figma picture. (1:01-3:04) — type: opinion/practice (personal)
- [UX] Project cycle: call the client and ask leading questions; commercial proposal with tariffs (full, partial, minimal scope); decode the brief; analyse audience and competitors; collect references; text prototype (block by block); design the first three blocks and approve before doing the rest; then mobile version; then layout. (3:04-8:10) — type: practice (one freelancer's process)
- [UX] Time budget in his example: prototype and design concept about 4 weeks, layout and integrations another 4 weeks; he says this cannot be done in a week and describes skipping stages for a lower price. (8:10-10:13) — type: opinion/practice
- [UX] Get references and agree them with the client before designing, to avoid redoing work. (7:08) — type: practice
- [UX] Soft skills sell more than technical skills: communication, empathy, being comfortable to work with. (11:15-12:17) — type: opinion
- [UX] Start practising immediately; do not stay in study mode. (12:17) — type: opinion

## Techniques and steps
1. Learn Figma and Tilda.
2. Learn each stage of a project cycle.
3. Practise on real briefs.

## Core thesis
Because GA4's interface is hard for small owners, and because Google is a privacy concern, try open-source privacy-friendly alternatives: Umami (free tier), Plausible (WordPress integration) or Matomo (power users).

## Claims and advice
- [ANALYTICS][PRIV] GA4 no longer stores IP addresses or other personal data because of GDPR; this limits user-level tracking. (1:03) — type: evidence (partly verified: Google says IP addresses are not logged or stored in GA4)
- [ANALYTICS] GA4's dashboard is hard to use for small owners. (0:00-2:05) — type: opinion
- [ANALYTICS][PRIV] Umami: open source, "gdpr compliant by default", "you don't need to show any cookie consent banners to use it"; free cloud plan up to 10,000 monthly events on 3 sites; $9 a month for 100,000 events; EU or US data location. (2:05-4:06) — type: evidence/opinion (consent-banner claim is legal, not verified)
- [ANALYTICS] Plausible: EU processing, official WordPress plugin, imports GA data, Search Console integration, can bypass ad blockers with a first-party proxy; $9 a month for 10,000 page views and 10 sites; some features reserved for the pricier plan. (5:07-7:09) — type: evidence (2024 prices)
- [ANALYTICS] Matomo: open source, EU servers, heatmaps, session recordings, imports GA data (into a new site), more complex; $26 a month for 50,000 views. (7:09-9:12) — type: evidence
- [ANALYTICS] Browsers with built-in tracker blocking (Brave, Opera, Firefox) hide visits from many trackers; Plausible makes a workaround easy. (9:12-10:13) — type: evidence
- [ANALYTICS] Fathom is an honourable mention; starts at $15 a month for 100,000 page views. (10:13) — type: evidence
- [ANALYTICS] Picks: Umami for a free basic option, Plausible for WordPress, Matomo for power users. (10:13-12:17) — type: opinion

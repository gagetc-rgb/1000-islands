## Core thesis
Choosing and combining fonts matters for aesthetics and reading comfort; keep to two typefaces; check that a font supports the scripts you need; keep headings as real heading tags.

## Claims and advice
- [TYPE] Find the font a site uses by inspecting the element in DevTools (name, size, colour, letter spacing). (1:00-3:02) — type: practice
- [TYPE][PERF] A site font is only available if the site sends the file to the browser; each extra font slows loading. (3:02-5:04) — type: practice
- [TYPE][SEO] Text that looks like text may be an image; headings should be real `h1`/`h2` tags because search engines use them. (5:04, 17:24-20:31) — type: practice
- [TYPE][A11Y] Do not fake a heading with a styled paragraph; keep a real heading and override its style (inherit) if needed. (14:20-20:31) — type: practice
- [TYPE] Cyrillic: Oswald, for example, has no Cyrillic glyphs (the Russian text fell back to another font); in Google Fonts use the language filter (Cyrillic) to find fonts that support it, such as Roboto; plan this at the start for multilingual sites. (20:31-25:39) — type: practice
- [TYPE][UI] "Two fonts per page is enough": one for headings and one for body; for non-designers stick to the rule. (25:39-27:43) — type: opinion
- [TYPE] Use Google Fonts' suggested pairings (for example Open Sans with Roboto) or ready combination packs (his pack of ten pairs, Playfair Display with Source Sans Pro). (27:43-29:46) — type: practice/promotion

## Techniques and steps
1. Filter the font list by script.
2. Choose one heading font and one body font.
3. Keep heading tags real.

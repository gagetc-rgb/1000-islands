## Core thesis
Google Search Console (GSC) is the most useful free SEO tool: submit the sitemap first, inspect URLs, then use the Performance report (clicks, impressions, CTR, average position) with period comparison to see what changes and why.

## Claims and advice
- [SEO] Submit the sitemap first (Squarespace: sitemap.xml; WordPress varies). (1:02-2:03) — type: practice
- [SEO] URL Inspection shows whether a page is indexed; "Request indexing" and "Test live URL" show what blocks it. (2:03-3:03) — type: practice
- [SEO][ANALYTICS] Performance report: clicks, impressions, average CTR, average position, filterable by query, page, country, device. (3:03-5:05) — type: evidence
- [SEO] Compare date ranges to see which queries and pages lost clicks; clicking a page or query filters the report; a click drop can be lower demand, not lower rank. (5:05-9:09) — type: practice
- [SEO] Keyword cannibalisation: filter by query and look at the Pages tab to see multiple pages competing. (10:10-11:11) — type: practice
- [SEO] Page indexing report explains why pages are not indexed ("Crawled - currently not indexed", "Not found"); fix broken pages with 301 redirects. (11:11-13:15) — type: practice
- [SEO] Removals tool for urgent or outdated pages. (13:15-14:16) — type: practice
- [PERF][SEO] Experience section lists pages with poor Core Web Vitals and mobile problems; focus on mobile. (14:16-15:17) — type: evidence
- [SEO][SEC] Manual actions and security issues appear in GSC. (15:17) — type: evidence
- [SEO] Links report shows external backlinks, internal links and anchor text, so you need no paid tool for basics; important pages should have many internal links. (15:17-19:20) — type: practice/opinion

## Techniques and steps
1. Verify the site, submit the sitemap.
2. Inspect key URLs; request indexing for new pages.
3. Review Performance monthly with comparison.
4. Check Page indexing and Experience reports.

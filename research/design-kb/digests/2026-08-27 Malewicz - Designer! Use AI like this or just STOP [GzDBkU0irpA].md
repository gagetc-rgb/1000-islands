## Core thesis
Most people use AI wastefully, mass-producing slop. Keep the core human (copy, user story, research, real photos) and use AI for what it is good at: data processing, edge cases, tweaking existing assets, flow diagrams and explaining concepts. The visual must come second and must serve the text.

## Claims and advice
- [AIS] Opening metaphor: we used computers on par with calculators to get to the moon and now use powerful devices "to launch birds at pigs"; AI is wasted potential when it produces slop. (0:00) — opinion
- [AIS][P] Do not generate the website copy with AI ("seamlessly empowering progressive transformations" babble). Write it yourself, then ask AI for angles on how it solves the user group's problem, rephrasings, power words and emotional triggers (and ask it to explain what those are). (0:00-2:03) — practice
- [AIS][Q] Spotting slop is a key skill: some visual patterns, colors and type choices are slop (some were slop before AI; AI boosted them); clients and good designers notice; he mutes accounts that post visibly low-effort work even if it looks good. (2:03-3:04) — opinion
- [Q][CL] "What actually sells on the website? The copy." A white background, headline, short description and a button beats an AI-generated anime background or "blobby light leak". Obsession with looks is mistaken. (3:04) — opinion
- [P] Start with type frames (text-only wireframes) and research; images are "artwork disguising as a product" if they come first. (3:04-4:04) — practice
- [VIS-I][AIS] You cannot make usable client website imagery from a single prompt "no matter what you write". Instead get real photos/visuals from the client (branding, staff, people doing the job) and use AI to tweak: swap background, raise colors. (4:04-5:05) — practice, from agency experience
- [VIS-I][VIS-C] AI as the new recoloring: before, designers recolored a photo (brown eyes to blue, a beige jacket cooler) to match a blue CTA; now AI does such swaps quickly, and this use is "completely overlooked". (5:05) — practice
- [P][EMO] Order: first write the problem and solution, then how it works, then a low-friction CTA, all in black and white; then add color, gradients, shadows and visuals; "that visual has to come from the text. It has to match and amplify the text. Otherwise, it has no reason for being there." (5:05-6:07) — practice
- [AI][P] Flow diagrams: write the user story by hand (AI only gives an average), let AI generate the diagram skeleton as editable canvas nodes, ask for all edge cases, then manually edit every node (what is on the screen, how it connects to business logic and goals, how it moves the user from problem to solution); convert to a type-frame prototype; then add visuals. (6:07-8:10) — practice
- [AI][AIS] AI is good at data processing, edge cases and anticipating client questions; the creative outputs (images, text) are only "superficially quality" and often visibly AI-generated, which makes many clients reject you. (8:10-9:11) — opinion
- [AI] Learn fundamentals (color theory, typography, grid, layout) by asking AI as a tutor: "learn first and do later. Don't rush." (9:11) — practice/opinion

## Techniques and steps
1. Write the user story and copy yourself; use AI to critique and expand angles.
2. Build a type-frame (text-only) version: problem, solution, how it works, low-friction CTA.
3. Collect real client photography; use AI only to adjust (background, color, retouch).
4. Add color and effects only after the black-and-white version works; every visual must reinforce the text.
5. For flows: write story, generate node skeleton, request edge cases, hand-edit each node, convert to prototype.

## Disagreements and contrarian points
Against "AI-generated hero art" as design and against writing copy with AI. Against the claim that a site needs to look beautiful to sell. Claims the creative strengths of generative AI are only superficial; sees data and edge-case work as the real strength.

## For 1000 Islands
Supports copy-first (type-frame) structure already in our Stage 1, and photography first: use real photos supplied by the owner (people, boats, places) and only retouch with AI (color match, crop, cleanup). Use AI for edge cases in the booking/enquiry flow rather than copy. Remember his warning that visibly AI-made images lose trust, critical for a travel brand. Low-friction CTA sequencing: problem, solution, how it works, CTA.

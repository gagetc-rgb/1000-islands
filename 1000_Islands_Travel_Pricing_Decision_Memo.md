# Pricing Decision Memo — 1000 Islands Travel

## Recommended commercial offer

### Main launch package
**IDR 25,000,000 one-off**

This is the recommended price for a proper commercial launch, not just “building a website”.

### Practical negotiation range
- **Target:** IDR 25m
- **Comfortable range:** IDR 22–27m
- **Floor:** about IDR 20m, but only by reducing scope
- **Do not discount the same scope below the floor.** Remove deliverables instead.

### After launch
- **Technical maintenance:** IDR 0.5–0.8m/month
- **Growth Lite:** IDR 3–4m/month
- **Growth + Ads management:** IDR 5–6m/month + ad spend

For a small family business, ongoing growth should be optional at launch. Start it only if the economics and lead volume justify it.

A cheap freelancer can build a functional WordPress site.

That is not the same deliverable.

The IDR 25m package combines:

**research + positioning + UX + design + development + CMS + acquisition pages + SEO foundation + analytics + conversion setup + project management**

The commercial value is in the full system.

Ukraine gives access to capable designers/developers at lower production cost than many Western agencies.

The client is paying for:

- QA

That is the correct place for a small family travel company:

# How to decide whether monthly growth is worth paying for

Do not argue that the client “must” spend every month.

Use unit economics.

Ask for:
1. inquiries per month
2. bookings per month
3. average booking value
4. approximate gross/contribution profit per booking
5. current lead sources

Then calculate:

**Required incremental bookings = monthly growth cost / contribution profit per booking**

Example:

If one additional booking contributes IDR 15m and growth work costs IDR 3.5m/month:

**3.5 / 15 = 0.23 bookings/month**

So roughly one additional booking every 4–5 months would cover the retainer.

If the economics do not support the spend, reduce or pause the retainer.
